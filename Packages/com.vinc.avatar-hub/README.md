# V.inc Avatar Hub

VRChat ギミック制作向けの Unity エディター拡張です。
**案件フォルダーの自動作成 → 「何を含めるか」のプロファイル登録 → UnityPackage の書き出し（単発・シーケンス）** を 1 つのウィンドウで行います。
複数の unitypackage を順番にまとめて入れる **インポート**（④） と、手で作った unitypackage からプロファイルを作る機能もあります。
よく使うフォルダーへすぐ飛べる **プロジェクトブックマーカー** と、アセットを使っているものを探す **アセットSearcher**、
複数のアバターを順番に続けて VRChat へ上げる **アバターアップローダー** もあります。

- メニュー：`V.inc / Avatar Hub`
- ウィンドウ：既定は独立したウィンドウ。前回閉じたときの位置と大きさで開きます（はじめては Unity 本体の中央）。最小サイズは 640×480（設定で Unity のタブとして開くようにもできます）
- 対応：Unity 2022.3（VRChat SDK / Modular Avatar 環境で動作確認）
- 依存パッケージなし（MA の参照もシリアライズ参照として追跡するため、MA の DLL を直接参照しません）。アバターアップローダーだけは VRChat SDK - Avatars 3.10.6 以降が入っているときに使えます（入っていなくてもほかの機能は動きます）

## 画面の流れ

| | 画面 | できること |
|---|---|---|
| ホーム | 何をしたいですか？ | やりたいことを選ぶと、注釈つきのスクリーンショットで手順を説明。「〜とは？」の解説、最近使ったもの |
| 設定 | 右上の「設定」 | テーマ（Unity のグレー・ダーク・ライト）、アクセントカラー、サイドバーに出すワークフロー、ウィンドウの開き方、効果音、保存場所 |
| ① | プロジェクト作成 | 名前を入れてチェックするだけでフォルダー一式を作成。作成場所（親フォルダー）の選択、タグ付け、あとからのフォルダー追加 |
| ② | プロファイル登録 | 自動登録（プレハブ/フォルダーをドロップ → 依存を自動チェック）、手動登録、UnityPackage から作る。名前・パッケージ名・タグ・書き出し先 |
| ③ | エクスポート | 単発：`名前 [種別] [Ver] [日付] [時刻]` をクリックで付け外し。シーケンス：複数をまとめて順番に書き出し |
| ④ | インポート | 複数の unitypackage をキューに並べて、上から順番にインポート。行ごとにプロファイルも作れる |
| ⑤ | プロジェクトブックマーカー | よく使うフォルダーを登録して、Project タブをクリック 1 回でその場所へ切り替え。Project タブの隣にブックマークのタブも出せる |
| ⑥ | アセットSearcher | 選んだアセットを使っているもの（テクスチャ → マテリアルなど）を、Assets 全体・フォルダー・プレハブの中から探す |
| ⑦ | アバターアップローダー | キューに並べた複数のアバターを、VRChat SDK を通して上から順番に続けてアップロード。最初に同意を押せば、あとは自動で進む |

上部の検索欄（Ctrl+F）で、プロジェクト・プロファイルを名前やタグから探せます。
ひらがな/カタカナ・全角/半角・大文字/小文字・`_` `-` の違いは無視します（例：「くじら」で「クジラ」タグがヒット）。

## 書き出し名のルール

```
productC                               … 何も付けない
productC_Ver0.0.1                      … バージョン
productC_Ver0.0.1-2026_10_25           … バージョン＋日付
productC_Ver0.0.1-2026_10_25-18_51     … バージョン＋日付＋時刻
productC_2026_10_25-18_51              … 日付＋時刻
productC_Debug_Ver0.0.1                … 種別（ラベルは設定で変更可）＋バージョン
```

- 名前の後ろは必ず `_`、バージョン・日付・時刻のあいだは `-`
- バージョンは 0.0.1〜9.9.9。上げると下の位は 0 に戻る（0.0.9 → 0.1.0、1.2.5 の真ん中 → 1.3.0）
- 初回は 1.0.0、2 回目以降は前回の番号が入り「前回のバージョンは〜でした」と表示
- シーケンスでは、日付・時刻は「エクスポート」を押した瞬間の値を全件に使う

## プロファイルの仕組み

- **フォルダーにチェック**＝中身ぜんぶ（**これから増えるファイルも**）。ファイル単位の除外もできる
- 「基準フォルダー」（プロジェクトのフォルダー）の**外**のファイルは「外部」扱いで、最初はチェックしない（アバター本体や他人の素材の混入防止）
- Packages 配下（VRCSDK・MA・lilToon など）は unitypackage に入れられないため対象外
- 書き出し時に起点プレハブの依存を再チェックし、**未登録の新しい依存**（入れ忘れ）や**見つからない登録**を警告
- 書き出すのは解決したファイルとその親フォルダーだけ（依存の自動追加はしない）

## UnityPackage から作る・インポート

手で作っていた unitypackage を Avatar Hub に移すための機能です。

- unitypackage の中身（GUID と元のパス）を、インポートせずに読みます。アセット本体は読み込みません
- プロジェクトとは **GUID** で照らし合わせます。インポートしたあとに移動・名前変更したファイルも、いまの場所で登録します
- まだ入っていないファイルがあれば、自動でインポートしてからプロファイルを作ります
- 登録するのは **入っていたファイルだけ**（フォルダーごとにはしません）。ほかのプレハブから使われていないプレハブを起点にして、次からの入れ忘れチェックに使います
- 名前とバージョンはファイル名から読みます（例：`Ring_Ver1.0.2-2026_10_28` → 名前 `Ring`、次のエクスポートは 1.0.2 の続きから）
- `Packages/` など Assets の外のファイルは、unitypackage に入れられないので登録しません
- 作ったプロファイルはすぐに保存します（Ctrl+Z で取り消せます）。注意点（入れ忘れの可能性・見つからないファイル）は結果に表示します
- 同じ unitypackage からもう一度作ったとき：中身がまったく同じプロファイルがあれば「既にあります」と出して作りません。同じ名前で中身が違えば、何が変わるかを見せて「上書きする（名前・タグ・書き出し先はそのまま）／別名で作る／作らない」を選んでもらいます

**名前の重なり**：プロファイルは同じ名前で保存しません。重なるときは「名前 (2)」のように番号を付けます（JSON のファイル名と同じ）。unitypackage の名前は元のままなので、書き出すファイル名は変わりません。以前のバージョンで同じ名前のまま保存されたもの（ファイル名だけ「(2)」）は、開いたときに名前をファイル名に合わせます。

**黄色の「!」（衝突）**：Unity のインポート画面で黄色の「!」が付くファイル（同じパスに GUID の違う別のファイルがある）は、そのまま入れるとプロジェクトのファイルが上書きされます。

- UnityPackage から作る：衝突があるときだけ「Unity の画面で入れる（入れるファイルを選べる）／このまま入れる（上書き）／やめる」を選びます。無ければ確認なしで入れます
- インポート：「止めて確認する（おすすめ）」か「無視して入れる」を選べます。止まった行では「Unity の画面で入れる／このまま入れる／飛ばす」を選ぶと続きを進めます

スクリプト入りのパッケージでは途中でコンパイル（ドメインリロード）が走りますが、キューは保存してあるので終わると続きから進みます。

## プロジェクトブックマーカー

- Project ウィンドウからフォルダー（またはアセット）をドロップして登録します。はじめは空で、各自が登録します
- 押すと、**最後に使ったロックなしの Project タブ** がその場所に切り替わります。ロック中のタブは動かしません（全部ロック中なら新しいタブを開きます）。選択中のもの（Inspector の表示）は変わりません
- アセットを登録した場合は、そのフォルダーを開いてアセットを光らせます
- ⑤の「ブックマークのタブを出す」で、Project タブの隣にブックマークだけのタブを出せます（Avatar Hub を開かなくても飛べます）
- PC 全体で共通です。JSON に書き出して人に渡せます。別の Unity プロジェクトでは、同じ場所（パス）にフォルダーがあるものだけ使えます

## アセットSearcher

- 選んだアセットを **使っているもの**（逆引き）を探します。例：テクスチャ → マテリアル、アニメーション → コントローラー
- 探す場所：Assets 全体 / フォルダーの中 / プレハブの中（どのオブジェクトの、どのコンポーネントの、どの欄が使っているか）
- ふだんは直接使っているものだけ。「その先もたどる」で、間にはさまっているもの（経由）も表示します
- アセットは読み込まず、Unity の依存関係の情報だけで探します（プレハブの中を調べるときだけ、そのプレハブを読み込みます）。検索は「検索」を押したときだけ動きます

## アバターアップローダー

- Hierarchy からアバターをドロップしてキューに並べます（親をドロップすると中のアバターを全部。「開いているシーンのアバターを全部追加」も可）。別のシーンのアバターも並べられます
- 使えるのは **一度アップロードしたことのあるアバター**（Pipeline Manager に Blueprint ID があるもの）の更新です。最初の 1 回は名前・サムネイルを決めるため、SDK の画面でアップロードしてください
- アップロードは VRChat SDK の公開 API（`IVRCSdkAvatarBuilderApi.BuildAndUpload`）で行います。始めると SDK の画面が前に出て、いまのアバターが選ばれます（ログインが必要）。進み具合は Avatar Hub の画面に出します。プラットフォームごとの差し替え（Per-Platform Overrides）も使います
- 最初に全員分の準備（VRChat 上のアバターの確認）と **著作権の同意**（SDK の画面に出る。Unity を起動してから初めてのアバターだけ）を済ませ、そのあとはビルドとアップロードを止まらずに続けます
- 失敗したとき：「飛ばして次へ（おすすめ）」か「止める」を選べます。最後に理由といっしょに一覧で出し、「失敗したものをもう一度」でそのアバターだけやり直せます（同意をしなくて飛ばしたものも含む）。SDK から完了の通知が来たときだけ「完了」にします（Dry Run の設定や通信切れを「完了」にしない）
- 「止める」：いまのアバターが終わったら止める／今すぐ中止（アップロード中のものを取り消す）
- 閉じているシーンのアバターは、その番になるとシーンを追加で開き、終わると保存せずに閉じます。開いているシーンはそのままなので、Avatar Hub が保存していない変更を保存したり捨てたりすることはありません（VRChat SDK がビルドの中で行う処理は除く）。同じ ID のコピーが別のシーンにあっても、登録したシーンのものだけを使います
- 非表示のアバターは、アップロードの間だけ表示にして、終わったら戻します
- いまの Unity のビルド先に向けてアップロードします。Android（Quest）にも上げるときは、ビルド先を切り替えてからもう一度実行してください
- 全部終わると効果音で知らせます（失敗があったときは確認待ちの音）。キューは Unity プロジェクトの `Library/VIAH` に保存し、途中で Unity の再読み込みがあったときはその行を「中断（要確認）」にして止めます
- VRChat SDK を呼ぶ部分は別のアセンブリ（`VInc.AvatarHub.VRChat`）で、SDK が入っているときだけコンパイルされます

## 効果音

時間のかかる作業が終わったとき（シーケンスエクスポート・単発エクスポート・インポート・UnityPackage から作る・アセットSearcher の検索・プロファイルの自動検出・アバターのアップロード）に「ピロリン」と鳴らします。
衝突や同じ名前のプロファイルで確認待ちになったとき、アップロードに失敗したものがあったときは、別の音（ピンポーン）で知らせます。

- 設定の「効果音」で、オン・オフ、音量、音の種類（ピロリン・キラリン・ピンポーン・ポーン・ポロン）、試し聴き、作業ごとのオン・オフを変えられます
- 「自分の音を選ぶ…」で wav / mp3 / ogg に入れ替えられます（保存場所の `Sounds` フォルダーにコピーするので、どの Unity プロジェクトでも同じ音になります）
- すぐ終わったとき（3 秒未満）は鳴らしません（設定で変えられます）
- 内蔵の音はこのツールがその場で合成した音で、音源ファイルは含みません
- Windows では Windows の機能で鳴らすので、Unity の「Mute Audio」には左右されません（音量は Windows の音量ミキサーの「Unity」でも変わります）

## 保存場所（すべて JSON）

PC 全体で共通です（どの Unity プロジェクトを開いても同じ一覧が出ます）。

| データ | 場所 | 共有 |
|---|---|---|
| フォルダー構成プリセット | `ドキュメント/V.inc/Avatar Hub/Presets/*.preset.json` | 書き出し / 読み込み |
| プロジェクト記録 | `ドキュメント/V.inc/Avatar Hub/Projects/*.project.json` | 書き出し / 読み込み |
| プロファイル | `ドキュメント/V.inc/Avatar Hub/Profiles/*.profile.json` | 書き出し / 読み込み |
| 設定 | `ドキュメント/V.inc/Avatar Hub/settings.json` | — |
| 書き出し履歴（前回のバージョン） | `ドキュメント/V.inc/Avatar Hub/history.json` | — |
| ウィンドウの位置と大きさ | `ドキュメント/V.inc/Avatar Hub/window.json` | — |
| プロジェクトブックマーカー | `ドキュメント/V.inc/Avatar Hub/bookmarks.json` | 書き出し / 読み込み |
| 効果音（自分の音） | `ドキュメント/V.inc/Avatar Hub/Sounds/` | — |
| インポートのキュー | `<Unityプロジェクト>/Library/VIAH/import-*.json`（Unity プロジェクトごと） | — |
| アップロードのキュー | `<Unityプロジェクト>/Library/VIAH/upload-queue.json`（Unity プロジェクトごと） | — |
| unitypackage の既定の出力先 | `<Unityプロジェクト>/Exports/`（設定・プロファイルごとに変更可） | — |

旧バージョン（Asset Organizer）のデータ（`%AppData%/V.inc/AssetOrganizer` と `<Unityプロジェクト>/AssetOrganizer`）は、初回起動時に自動でコピーして引き継ぎます。

## 元に戻す（Undo）

Ctrl+Z / Ctrl+Y（Edit メニューにも「VIAH: 〜」として表示）。入力途中の内容、フォルダー構成の編集、プロファイルの選択、保存・削除・複製・読み込み、設定の変更、インポート・アップロードのキューの編集、ブックマークの変更、フォルダーの作成（取り消すと空のフォルダーを削除）を戻せます。
unitypackage・JSON の書き出し、unitypackage のインポート（入ったファイルはそのまま。一緒に作ったプロファイルは戻せます）、画面の移動・検索は戻せません。画面を移ると、その画面の入力途中の Undo は消えます。

アセットは GUID とパスの両方で記録するため、フォルダーを移動・リネームしても追従します。
他の人のプロファイルを使うときは、同じアセット（同じ GUID）がプロジェクトに入っている必要があります。

## 開発用テスト

`Tests/Editor` の自己テスト・画面テスト・通しテストは、スクリプト定義シンボル `VINC_VIAH_DEV` を追加したときだけコンパイルされます
（Player Settings → Scripting Define Symbols）。有効にするとメニュー `V.inc / 開発` から実行できます。
テストは `Assets/VIAH_Sample` などのサンプルを作るので、確認後は削除してください。
